# scam-or-legit
a basic Python program that identifies common warning signs in suspicious messages.

## Features
- Accepts a message from the user
- Checks for suspicious words and phrases
- Counts the warning signs found
- Displays a simple caution result

## How It Works
The program searches for predefined words such as "urgent",
"winner", "prize", and "click here". It then displays the
warning signs it finds and gives a basic result.

## Requirements
- Python 3

## How to Run
1. Download the file `scam_or_legit.py`.
2. Open a terminal in the folder containing the file.
3. Run:

   python scam_or_legit.py

4. Enter a sample message when prompted.
5. Read the result displayed by the program.

## Python Concepts Used
- Variables
- Lists
- User input
- Loops
- Conditional statements
- String methods

## Disclaimer
This is an educational project, not a real phishing detector.
It may miss dangerous messages or flag harmless ones.
Never enter private information when testing the program.
